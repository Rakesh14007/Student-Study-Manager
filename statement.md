# Project Statement

## Project Title

Student Study & Task Management System

## Problem Statement

Students often have multiple academic tasks, assignments, deadlines, and study sessions to manage. Without proper organization, it can become difficult to keep track of pending tasks and monitor study time.

The Student Study & Task Management System provides a simple Python-based solution for managing academic tasks and study sessions in one place.

## Scope

The system focuses on basic academic task and study management through a command-line interface.

The system allows users to:

- Create and manage academic tasks
- Track task completion status
- Record study sessions
- View study records
- View task and study statistics
- Store data for future use

## Target Users

The primary target users are:

- College students
- School students
- Students who want to organize their academic tasks and study sessions

## High-Level Features

### Task Management
- Add tasks
- View tasks
- Complete tasks
- Delete tasks
- Track task status

### Study Management
- Add study sessions
- Record subject and topic
- Record study duration
- View study sessions

### Statistics and Reports
- Total number of tasks
- Completed tasks
- Pending tasks
- Total study time
- Subject-wise study time

### Data Management
- Store task data using JSON
- Store study session data using JSON
- Preserve data between program executions

### Validation and Error Handling
- Prevent empty inputs
- Validate numerical values
- Handle invalid user input
